# 理财产品净值监控设计

## 背景

在 `auto_faribao` 中新增一个净值监控能力，每天北京时间 08:00 自动查询配置的理财产品净值，并通过企业微信自建应用推送净值涨跌信息。服务最终部署在 Linux 上，因此实现必须使用跨平台 Python 能力，不能依赖 Windows `curl.exe` 或桌面浏览器。

首批默认产品为信银理财：

- 慧盈象固收增强一年持有期5号B，产品代码 `AF233276B`
- 慧盈象固收增强六个月持有期1号B，产品代码 `AF233262B`

设计同时预留并首版支持南银理财公募产品。已验证南银公开产品列表和净值接口可用，但南银站点需要特殊的加密请求和 TLS 兼容处理。

## 目标

- 定时推送：每天北京时间 08:00 推送一次配置产品的最新净值涨跌。
- 手动查询：企业微信指令支持立即查询最新净值。
- 指定日期查询：企业微信指令支持查询指定日期净值。
- 动态配置：企业微信指令支持查看配置、开关监控、修改推送时间、添加/删除产品。
- 多供应商：首版支持信银理财和南银理财，通过统一接口归一化数据。
- Linux 部署：所有生产路径使用 Python 跨平台实现。

## 不做范围

- 不做投资建议、收益预测或风险评级判断。
- 不做私募产品登录态查询。
- 不做 Web UI。
- 不用 Playwright 作为净值查询主路径；只有未来公开接口彻底失效时才考虑人工确认后的兜底方案。

## 配置设计

在 `config.yaml` 增加 `nav_monitor`：

```yaml
nav_monitor:
  enabled: true
  push_hour: 8
  push_minute: 0
  products:
    - provider: citic_wealth
      code: AF233276B
      name: 慧盈象固收增强一年持有期5号B
    - provider: citic_wealth
      code: AF233262B
      name: 慧盈象固收增强六个月持有期1号B
```

产品字段：

- `provider`：`citic_wealth` 或 `nanyin_wealth`
- `code`：供应商产品代码或销售代码
- `name`：企业微信展示名；添加产品时必须先由供应商接口验证并回显给用户确认，确认后写入配置

## 数据源设计

新增 `src/nav_monitor.py`，内部按供应商拆分适配器，但对调度器和企业微信命令暴露统一服务。

统一数据结构：

```python
NavRecord(
    provider: str,
    code: str,
    name: str,
    nav_date: date,
    unit_nav: Decimal,
    cumulative_nav: Decimal | None,
    source: str,
)
```

统一能力：

- `fetch_latest(product) -> list[NavRecord]`：返回按日期倒序的最近记录，至少用于最新和上一条对比。
- `fetch_by_date(product, target_date) -> DateQueryResult`：查询指定日期；优先精确匹配该日期，若当天没有披露，则返回该日期之前最近一条并标记为非精确匹配。
- `search_products(query) -> list[ProductCandidate]`：按产品代码、销售代码、登记编码或名称关键词查询候选产品，用于添加产品前验证。
- `get_product_identity(code) -> ProductCandidate | None`：按精确代码查询产品身份，用于确认产品存在且供应商可识别。
- `health_check() -> ProviderHealth`：用于启动或手动检查时发现供应商不可用。

信银理财：

- 使用公开 H5 接口。
- 搜索和详情接口用于补齐产品名称。
- 历史净值接口返回 `navDate`、`nav` 等字段，归一化为 `NavRecord`。
- 请求使用普通 `requests`。

南银理财：

- 使用南银官网公募产品公开页背后的 eportal 接口。
- 请求流程为：先访问公募产品页面建立 cookie，再获取服务端 RSA 公钥，再用随机 AES key 加密业务参数，用 RSA 公钥加密 AES key，POST 到产品列表或净值接口。
- 使用 `ssl.create_default_context()`，仅对 `www.nanyinwealth.com` 的客户端打开 `SSL_OP_LEGACY_SERVER_CONNECT`；当 Python 未暴露该常量时使用 OpenSSL 对应值 `0x4`。
- 使用 `http.cookiejar.CookieJar` 保持会话，不依赖系统 `curl`。
- 新增依赖 `pycryptodome` 处理 AES/RSA。
- 如果 Linux 运行环境因 OpenSSL 策略禁止 legacy server connect，南银适配器返回清晰错误，定时推送里标记该供应商失败，不影响信银产品推送。

## 涨跌计算

最新推送：

- 对每个产品取最新记录和上一条记录。
- 计算 `delta = latest.unit_nav - previous.unit_nav`。
- 计算 `delta_pct = delta / previous.unit_nav * 100`。
- 如果只有一条记录，则展示最新净值并提示“暂无上一条净值，无法计算涨跌”。
- 如果最新披露日期不是预期最近交易日或明显早于查询日，则在消息里标记“未更新到预期日期”。

指定日期查询：

- 指令日期格式固定为 `YYYY-MM-DD`。
- 对每个产品查询该日期。
- 若精确命中该日期，展示该日净值，并与该日期之前最近一条记录计算涨跌。
- 若未精确命中，展示“该日未披露”，同时给出该日期之前最近一条可用净值；如仍有上一条记录，则计算这两条披露记录之间的涨跌。

## 企业微信指令

新增净值类指令，命令匹配应放在更通用的“查看配置/帮助”之前，避免被已有子串规则误命中。

查询类：

- `立即查询净值`
- `查询净值`
- `净值监控`

含义：立即查询所有已配置产品的最新净值，并发送与自动推送相同格式的涨跌消息。

指定日期查询：

- `查询净值 2026-07-07`
- `查询指定日期净值 2026-07-07`
- `净值 2026-07-07`

含义：查询所有已配置产品在指定日期的净值。日期必须是 `YYYY-MM-DD`，格式错误时返回用法示例。

配置类：

- `查看净值配置`
- `开启净值监控`
- `关闭净值监控`
- `设置净值推送时间 08:00`
- `添加净值产品 信银 AF233276B 慧盈象固收增强一年持有期5号B`
- `添加净值产品 南银 NYZY000022 南银理财致远一年定开19期-A份额`
- `删除净值产品 AF233276B`
- `删除净值产品 NYZY000022`

添加产品时供应商别名：

- 信银、信银理财、citic、citic_wealth -> `citic_wealth`
- 南银、南银理财、nanyin、nanyin_wealth -> `nanyin_wealth`

产品添加验证与确认：

- `添加净值产品 信银 AF233276B` 这类指令不会直接写入配置，而是先调用对应供应商的产品查询接口验证产品存在。
- 如果精确代码只命中一个产品，企业微信回复该产品的供应商、代码、名称、登记编码或销售代码、最新可用净值日期，并提示用户回复 `确认添加净值产品 1`。
- 如果名称或关键词命中多个候选，最多展示 5 个候选，并要求用户用序号确认。
- 如果没有命中产品，回复“未找到该产品”，并提示改用产品代码、销售代码、登记编码或更完整名称。
- 待确认信息保存为短期 pending 状态，默认 5 分钟过期；过期后需要重新发送添加指令。
- 用户确认后再次检查配置中是否已有同供应商同代码产品，避免重复添加。
- 用户也可以回复 `取消添加净值产品` 放弃本次 pending 添加。
- 只有确认后的候选产品会写入 `config.yaml` 并立即刷新运行时配置。

## 推送消息格式

自动推送标题：

```text
# 理财净值日报
查询时间：2026-07-08 08:00
```

单产品展示：

```text
## 慧盈象固收增强一年持有期5号B
代码：AF233276B
最新：2026-07-07  1.078000
上期：2026-07-06  1.078100
涨跌：-0.000100（-0.0093%）
```

指定日期未精确命中：

```text
## 南银理财致远一年定开19期-A份额
代码：NYZY000022
查询日期：2026-07-02
状态：该日未披露
最近披露：2026-06-26  1.000000
```

## 调度集成

在 `src/scheduler.py` 增加净值监控任务：

- 每 30 秒循环中判断当前北京时间是否到 `nav_monitor.push_hour:push_minute`。
- 每天只推送一次，用内存中的日期标记避免同一分钟重复发送。
- 默认不限制工作日，因为理财净值披露可能跨工作日延迟；如果当天没有新披露，只在消息中说明。
- `update_runtime_config(cfg)` 同步更新净值推送时间和开关状态。

## 错误处理

- 单个产品失败不影响其他产品，消息中展示该产品失败原因摘要。
- 单个供应商失败不影响其他供应商。
- 网络超时使用短超时和有限重试，避免占用现有日报服务线程。
- 南银 TLS 或加密流程失败时返回“南银理财接口暂不可用”并记录日志。
- 企业微信手动查询走后台线程，先回复“正在查询”，避免回调超时。

## 验收标准

- Linux 部署环境不依赖 Windows 命令、桌面浏览器或人工登录。
- 每天 08:00 自动推送配置产品净值涨跌。
- 企业微信发送 `立即查询净值` 能收到最新净值涨跌。
- 企业微信发送 `查询净值 YYYY-MM-DD` 能收到指定日期查询结果。
- 企业微信可修改推送时间且立即生效。
- 企业微信添加产品必须先验证产品存在并由用户确认；未确认或未命中的产品不会写入配置。
- 信银默认两只产品开箱即用。
- 南银产品可通过企业微信添加并查询；若 Linux TLS 策略不兼容，错误清晰可见且不影响信银。
