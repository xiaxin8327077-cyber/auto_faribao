# 日报中文编号设计

## 目标

将智能文档生成的新日报正文编号由阿拉伯数字加句点改为中文数字加顿号：

```text
一、【监管数核工具】修复生产环境已知bug：修复生产环境已知bug
二、【监管数核工具】优化对账逻辑：优化匹配规则
十一、【项目名称】其他任务
```

## 实现

在 `src/processor.py` 增加独立的正整数中文数字转换函数，`format_report()` 使用转换结果生成编号。实现不引入第三方依赖，并支持个位、十位、百位及更高常见任务序号，正确处理 `十`、`十一`、`二十`、`一百零一` 等形式。

## 影响范围

- 智能文档提取后新生成的日报正文使用中文编号
- 项目名称、任务名称和任务描述格式保持不变
- 历史 OA 日报正文不改写
- 指定日期查询仅返回历史原文，不改写编号
- 手工输入的日报正文不改写
- 净值功能不受影响

## 测试

- 验证 1、2、10、11、20、21、101 等数字转换
- 验证日报多条任务输出为 `一、`、`二、`
- 验证项目名称前缀和任务文本保持原样
- 运行日报恢复、查询及完整测试集
