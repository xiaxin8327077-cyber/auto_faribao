# LongCat 诊断目标路由设计

## 问题

调度快照同时包含“日报提交”和“日报统计”。用户询问“为什么没发日报”时，LongCat 将“发”误解为统计推送，选择了错误的任务时间和日志，导致结论与真实日报提交流程无关。

## 设计

诊断 Agent 在首次模型调用前使用本地规则生成诊断目标：

- 包含“理财”或“净值”的日报问题：理财净值日报。
- 明确包含“统计、周报、月报、季报、半年报、年报”的问题：日报统计推送。
- 其余包含“日报”的问题：日报自动提交，并明确标注“不是日报统计推送”。
- 其他问题：不增加目标提示。

目标提示同时进入规划阶段和最终报告阶段，模型只能围绕该目标选择配置字段、日志关键词和结论。调度快照把“日报统计”重命名为“日报统计推送（仅周日/月末）”，降低字段歧义。

## 边界

- 不改变定时任务、提交、统计推送和消息发送行为。
- 不增加工具或模型调用次数。
- 不允许模型覆盖本地确定的诊断目标。

## 验收

- “为啥还没发日报今天”在两个模型阶段均带有“日报自动提交（不是日报统计推送）”。
- 日报统计配置明确显示仅周日/月末。
- 现有净值日报和通用诊断测试保持通过。
