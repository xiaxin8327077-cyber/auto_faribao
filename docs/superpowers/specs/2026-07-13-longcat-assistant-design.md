# LongCat 企业微信智能助手设计

## 目标

在不改变现有日报、理财净值、定时推送和网页看板业务口径的前提下，增加：

1. LongCat 自然语言指令路由。
2. 显式触发的多轮聊天。
3. 只读线上日志、运行状态和源代码诊断。

不实现自动修改代码、自动测试、自动部署或自动运维。

## 已确认环境

- 本地 `D:\cherry\auto_faribao` 与线上 `/home/ubuntu/daily_report` 的相关源码内容一致，哈希差异仅来自换行符。
- 线上为 2 核、1.6GB 内存、无 Swap；主服务当前约 165MB，历史峰值约 714MB。
- LongCat API 从首尔服务器可访问。
- `src.server` 已有进程内 `_cmd_busy` 全局命令锁。

因此 AI 能力运行在主服务的受控工作线程中，不增加第二个常驻 Python 服务。这样可以直接复用命令锁、避免额外内存，并严格满足“有进行中的指令时不调用模型”。

## 消息优先级

1. Cookies 更新、待确认回复、帮助导航和现有确定性指令优先。
2. 已有确定性规则能够识别时，不调用 LongCat。
3. 未识别消息、显式聊天和诊断请求才进入 AI 层。
4. `_cmd_busy` 为真时，AI 请求直接返回现有系统繁忙消息，不发起 HTTP 调用。
5. AI 处理期间占用同一个命令锁，避免聊天、诊断和其他耗时指令并发。

## 第一阶段

### 指令路由

LongCat 将自然语言转换为现有标准指令。输出必须是本地校验的 JSON，标准指令必须命中白名单。查询类直接交给现有处理链；修改、删除、提交、重启等写操作如果来自 AI 路由，则先保存待确认指令，用户回复“确认执行”后才交给现有处理链。

模型不能返回函数名、Shell、路径、URL或任意代码作为可执行内容。

### 聊天

- `问助手 <内容>`：单次聊天并保存上下文。
- `进入助手模式`：后续普通消息进入聊天。
- `退出助手模式`：清除模式和上下文。
- 每个企业微信用户最多保留最近 10 轮。
- 聊天默认不读取业务数据、日报正文、配置或日志。

## 第二阶段

### 诊断入口

支持“为什么今天没自动发送理财净值日报”“昨天日报为什么提交失败”“为什么没有执行兜底”等自然语言问题。诊断请求异步执行，先发送受理消息，再由 Agent 自主选择只读工具。

### 只读工具

- `get_schedule_snapshot`：工作日、日报和净值定时配置。
- `get_service_snapshot`：服务状态、运行时间、负载、内存和磁盘摘要。
- `search_logs`：固定服务、限定时间和数量的日志检索。
- `search_source`：在项目 Python 源码中搜索文本。
- `read_source`：读取白名单源码的限定行段。

禁止读取 `config.yaml`、`.env`、私钥、Cookie、`data/`、`runtime/`、`backups/` 和虚拟环境。工具输出统一脱敏，日志与源码内容均视为不可信数据，不能改变 Agent 指令。

### 运行限制

- Agent 并发固定为 1，并与现有命令共用忙碌状态。
- 每次诊断最多 8 次工具调用。
- 总执行时间最多 30 秒。
- 单次日志最多 120 行、12000 字符。
- 单次源码读取最多 200 行；搜索最多返回 50 项。
- 超时、限流、输出非法或工具失败时结束诊断，不影响现有服务。

## 配置与授权

只从 Linux 环境变量读取：

- `LONGCAT_API_KEY`
- `LONGCAT_ENABLED`，默认关闭
- `LONGCAT_BASE_URL`，默认 `https://api.longcat.chat/openai`
- `LONGCAT_MODEL`，默认 `LongCat-2.0`
- `LONGCAT_DIAGNOSTIC_USERS`，允许诊断的企业微信用户 ID 列表

API Key、完整提示词、聊天正文和工具原始输出不写日志。审计日志只记录用户 ID 摘要、请求类型、耗时、工具名、结果状态和错误类别。

## 失败与回退

- 未配置或关闭 LongCat：系统保持当前行为。
- 路由失败：提示 AI 暂时不可用，并给出现有帮助入口。
- 聊天失败：清晰提示失败，不重试执行任何业务指令。
- 诊断失败：返回已完成的检查项和失败原因，不输出猜测性结论。
- LongCat 不参与收益计算、净值披露判断、定时调度和消息去重。

## 验收

- 当前全部测试通过。
- 现有精确指令不调用 LongCat。
- 命令忙碌时 LongCat 客户端调用次数为 0。
- 非白名单标准指令无法执行。
- AI 路由出的写操作必须确认。
- 诊断工具无法越界读取敏感路径或执行任意命令。
- 工具调用超过 8 次或运行超过 30 秒会终止。
- LongCat 不可用时日报、净值和定时任务行为不变。
